# Spam Feeds v2.0

Экран «Настройки → Управление подписками» показывает название, URL, переключатель
активности и локализованную дату последней успешной синхронизации. FAB открывает
диалог добавления (имя и HTTPS URL); удаление требует подтверждения. Новые подписки
из UI включены сразу. Отключение или удаление прекращает будущие загрузки; ранее
скачанные записи остаются до истечения TTL 14 дней.

`SpamFeedRepository` предоставляет CRUD;
`SpamFeedDao` — наблюдение списка и выбор активных подписок.

## Рекомендованная подписка

И на новой установке, и после миграции Room 6 → 7 создаётся запись:

| Поле | Значение |
| --- | --- |
| id | 1 |
| name | Recommended database |
| url | `https://1byte.uz/spam_base.json` |
| isActive | true |
| lastSync | 0, пока синхронизация не завершилась успешно |

Существующие записи и настройки миграция не удаляет. Новая подписка, создаваемая через
конструктор без явного `isActive`, неактивна до её включения.

## Формат JSON

Поддерживаются массив объектов, объект с массивом `numbers` и экспорт CallGuard версий 1/2.
Сетевая запись обязана содержать целую оценку `spamScore` или `score` от 0 до 100:
пропуск поля не должен превращать неизвестный номер в блокирующую запись с оценкой 100.

```json
{
  "numbers": [
    {
      "numberHash": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "spamScore": 45,
      "category": "advertising"
    }
  ]
}
```

Хэш в примере синтетический. Вместо SHA-256 можно передать строку `phoneNumber`
(алиас `number`), которая нормализуется и хэшируется на устройстве. Если переданы и номер,
и хэш, они должны соответствовать друг другу. В глобальную таблицу открытый номер не записывается.
Длина категории ограничена 80 символами, число записей — 50 000, размер JSON — 5 МБ.
Проверяется весь документ: при ошибке любой записи фид не сохраняется частично.

## Сеть и сохранение

- Только HTTPS с обычной проверкой TLS; userinfo и fragment в URL запрещены.
- Автоматические редиректы отключены: допускается до пяти переходов с повторной проверкой URL/хоста.
- Перед соединением проверяются разрешённые публичные адреса; localhost, private/link-local и multicast отклоняются.
  Это предварительная DNS-проверка, а не закрепление IP: `HttpURLConnection` самостоятельно устанавливает TLS-соединение.
- Connect timeout — 10 секунд, read timeout — 15 секунд; дополнительно проверяется общий дедлайн загрузки.
- Ограничение размера применяется и к распакованному gzip. Некорректный UTF-8 отвергается.
- Запросы — только GET. Код не добавляет номера звонков, SMS, контакты, авторизацию или тело запроса.
- URL и тело ответа не пишутся в логи: только ID фида, тип ошибки и HTTP-код.
- Успешный JSON сохраняется транзакционно вместе с `lastSync`. Изменённый/удалённый/отключённый фид не коммитится.
- Ошибка одной подписки не останавливает последующие. Отмена Worker распространяется как отмена корутины.
- Неудачные подписки получают до трёх повторов Worker с backoff WorkManager; успехи уже сохранены.
- Глобальные записи старше 14 дней удаляются; локальные записи защищены от перезаписи и TTL.

Сеть проверяется unit-тестами на подставных HTTP-соединениях без внешних серверов.
Реальный ответ `1byte.uz` не удалось проверить в облачной среде: домен не входит в её сетевой allowlist.
Это не устанавливает состояние доступности самого сервера и не ограничивает сеть установленного Android-приложения.
